[pre-lab] 1. Ping pong

Write a multi-threaded program that simulates a game of ping pong between two players, each of whom is represented by a thread. One player hits the ball by printing "ping"; the other player hits the ball by printing "pong". The program should allow either player to hit the ball first (depending on which thread is faster), then the players should alternate until each player has hit the ball 5 times. Use a command-line argument to control the value of the deterministic flag passed to cpu::boot

[pre-lab and in-lab] 2. Piano

Write a multi-threaded program that simulates a conductor directing musicians to play music. The conductor thread reads a series of notes (the note value is in the range 0-7) from an input file and directs different musician threads to play each note. Each musician thread plays a single type of note by printing an appropriate string (0=empty, 1=do, 2=re, 3=mi, 4=fa, 5=sol, 6=la, 7=ti).

Based on the ping pong lab activity, implement a correctness checker in some scripting language, which tests the output of your solution. Your correctness checker should take in the printed output of a ping pong solution, and determine whether or not it is valid according to the spec.
