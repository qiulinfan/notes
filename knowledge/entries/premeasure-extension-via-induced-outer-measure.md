# premeasure extension via induced outer measure

## Summary

Any premeasure can induce an outer measure: $ mu^(*)\(E\)= inf { sum_(i = 1)^oo mu_0\(A_i\)divides A_i in cal(A)_0\,E subset.eq union.big_(i = 1)^oo A_i } $ 并且, we have: $ mu^(*)\|_(cal(A)_0)= mu_0 $ 并且 every set in $cal(A)_0$ is $mu^(*)$-measurable.
