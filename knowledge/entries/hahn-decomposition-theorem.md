# Hahn Decomposition Theorem

## Summary

对于任意 measurable space $\(X\,cal(A)\)$ 上的任意 signed measure $nu$, 都存在一个 positive set $P$ 和一个 negative set $N$ s.t. $ P inter N = diameter $ 并且 $ P union.sq N = X $ 即$X$ 被 $nu$ 划分为一个 positive measure space 和一个 negative measure space. \ 并且, 这个 decomposition 是唯一的, in $nu$-a.e. sense: 即, 如果 $P'\,N'$ 是 another pair of such decomposition, 必然有: $ P Delta P' = N Delta N' quad upright("is null set") $
