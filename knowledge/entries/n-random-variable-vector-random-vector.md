# 由 n 个 random variable 构成的 vector 是一个 random vector

## Summary

若 X_1,...,X_n 是定义在同一 probability space 上的 random variables，则 omega 映到 (X_1(omega),...,X_n(omega))^T 的函数是 random vector。
