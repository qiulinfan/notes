# 使用 a sum of indicator functions of measurable sets 来定义 simple function

## Summary

对于 simple function $phi.alt : X arrow.r bb(C)$ s.t. $phi.alt\(X\)= { c_1\,dots.h.c\,c_n }$, 我们也可以定义它为: $ phi.alt\(x\)= sum_(j = 1)^n c_j chi_(E_j) $ 其中, $E_j = phi.alt^(- 1)\({ c_j }\)$. 我们称之为: the standard representation of simple $phi.alt$.
