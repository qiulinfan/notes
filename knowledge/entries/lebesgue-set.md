# Lebesgue set

## Summary

我们定义一个函数 $f in L_(l o c)^1\(bb(R)^n\)$ 的 Lebesgue set 为: $ L_f := { x in bb(R)^n divides lim_(r arrow.r 0^(+)) "avg"_(B\(x\,r\))\|f\(y\)- f\(x\)\| d y = 0 } $ 其中每个 point 被称为一个Lebesgue point.
