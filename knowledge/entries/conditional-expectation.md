# conditional expectation

## Summary

conditional expectation E[X|Y=y] 是 x 对 conditional distribution P^{X|Y=y} 的积分；discrete case 为加权和，continuous case 为 x f_{X|Y}(x|y) 的积分，并可视为 y 的函数。
