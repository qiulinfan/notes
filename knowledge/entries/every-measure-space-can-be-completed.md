# every measure space can be completed

## Summary

Suppose $\(X\,cal(M)\,mu\)$ is a measure space. \ Let $ cal(N) := { upright("all null sets in ") cal(M) } $ Claim: $ accent(M, macron) := { E union F divides E in cal(M)\,F subset.eq N upright(" for some ") N in cal(N) } $ is a $sigma$-algebra, 并且在 $accent(cal(M), macron)$ 上存在一个 unique 的 extension $accent(mu, macron)$ of $mu$.
