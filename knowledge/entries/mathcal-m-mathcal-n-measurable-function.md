# (cal(M),cal(N))-measurable function

## Summary

Let $\(X\,cal(M)\)$, $\(Y\,cal(N)\)$ be measurable spaces, 如果 $f : X arrow.r Y$ 满足: $ B in cal(N) arrow.r.double.long f^(- 1)\(B\)in cal(M) $, 则称 $f$ 为一个 $\(cal(M)\,cal(N)\)$-measurable function.
