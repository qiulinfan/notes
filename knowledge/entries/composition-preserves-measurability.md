# composition preserves measurability

## Summary

如果 $f$ 是 $\(cal(A)\,cal(B)\)$-measurable 的, $g$ 是 $\(cal(B)\,cal(C)\)$-measurable 的, 那么 $g compose f$ 是 $\(cal(A)\,cal(C)\)$-measurable 的.
