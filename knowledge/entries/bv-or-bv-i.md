# 哪些函数一定 B V or B V(I)

## Summary

+ 如果 $F : bb(R) arrow.r bb(R)$ bounded 且 increasing, 那么 $F in B V$ 且 $T_F\(x\)= F\(x\)- F\(- oo\)$. \ + 如果 $F : bb(R) arrow.r bb(R)$ 是 Lipschitz countinuous 的, 那么$F in B V\(I\)$ for 任意的 cpt interval $I$ + 如果 $F : bb(R) arrow.r bb(R)$ 是 differentiable 且 $F'$ bounded 的, 那么 $F in B V\(I\)$ for 任意的 cpt interval $I$
