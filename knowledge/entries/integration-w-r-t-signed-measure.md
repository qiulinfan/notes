# integration w.r.t. signed measure

## Summary

对于 signed measure $nu$, 我们 set: $ L^1\(nu\): = L^1\(\|nu\|\)= L^1\(nu^(+)\)inter L^1\(nu^(-)\) $ 且对于每个 $f in L^1\(nu\)$, 我们 set: $ integral f thin d nu : = integral f thin d nu^(+) - integral f thin d nu^(-) $
