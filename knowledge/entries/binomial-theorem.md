# Binomial Theorem

## Summary

对 x,y∈ℝ 与 n∈ℕ，Binomial Theorem 给出 (x+y)^n = ∑_{k=0}^n binom(n,k)x^{n-k}y^k；组合解释把系数视为从 n 个因子中选择 y 项的位置数。
