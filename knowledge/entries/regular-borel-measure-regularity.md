# regular Borel measure: 蕴含了 regularity

## Summary

一个 regular Borel measure $nu$ on $bb(R)^n$ 一定满足: + outer regularity: $ nu\(E\)= inf { nu\(U\)divides E subset U upright(" open") } $ + inner regularity: $ nu\(E\)= inf { nu\(U\)divides E subset U upright(" open") } $
