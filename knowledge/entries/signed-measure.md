# signed measure

## Summary

一个 signed measure on a measurable space $\(X\,cal(A)\)$ 是一个 function $nu : cal(A) arrow.r\[- oo\,oo\)$ 或者 $nu : cal(A) arrow.r\(- oo\,oo\]$, 和普通 meausre 一样满足 $nu\(diameter\)= 0$ 以及 ctbl disjoint additivity. \ Note: signed measure 只 admit $+ oo$ 和 $- oo$ 中的一个值 (不可以同时存在两个集合 $nu\(A\)= oo$, $nu\(B\)= - oo$)
