# distribution function is increasing and right ctn

## Summary

对于 $bb(R)$ 上的任意 locally finite Borel measure $mu$, 其 distribution function $F_mu$ 都是 increasing 且 right continuous 的. (right ctn:$ F_mu\(a\)= lim_(x arrow.r a^(+)) f\(x\) $
