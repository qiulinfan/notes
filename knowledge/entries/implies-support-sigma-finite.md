# 积分收敛 arrow.r.double.long 发散点集零测, 以及 support σ-finite

## Summary

如果 $f in L^(+)\(mu\)$ 且 $\|integral f\|< oo$, 则有: $ mu\({ x in X divides f\(x\)= oo }\)= 0 $ 并且 $ { x divides f\(x\)> 0 } $ is $sigma$-finite
