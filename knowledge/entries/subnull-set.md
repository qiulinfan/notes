# subnull set

## Summary

对于 [measure space] $\(X\,cal(M)\,mu\)$, 其中 $mu$ 是相应的 [measure], + 我们称 $A in cal(M)$ 为一个 null set, 如果 $mu\(A\)= 0$\; + 我们称 $B subset.eq X$ 为一个 subnull set, 如果存在某个 null set $A$ containing it. + 我们称一个 statement about $X$ 是 almost everywhere (a.e.) 的, 如果这个 statement 除了在某个 null set 上之外, 在 $X$ 上处处成立.
