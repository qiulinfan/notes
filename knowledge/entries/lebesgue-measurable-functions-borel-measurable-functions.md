# Lebesgue measurable functions, Borel measurable functions

## Summary

Naturally, 如果 $f : bb(R) arrow.r bb(C)$ 是一个 $frak(L)$-measurable 的函数, 那么我们称 $f$ 是 Lebesgue measurable 的. 同样地, 如果它是一个 $cal(B)\(bb(R)\)$-measurable 的函数, 称 $f$ 是 Borel measurable 的.
