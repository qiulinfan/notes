# HL maximal theorem

## Summary

For $L^1\(m^n\)$, take constant $C := 3^n$, 则对于任意 $f in L^1\(m^n\)$, 都有: $ m\({ x : H f\(x\)> alpha }\)lt.eq C / alpha integral\|f\| $
