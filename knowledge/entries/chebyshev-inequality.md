# Chebyshev's inequality

## Summary

对于 measure space $\(X\,cal(M)\,mu\)$, 如果 $f in L^(+)\(mu\)$ 并且 $c > 0$, 那么 $ mu { f gt.eq c } lt.eq 1 / c integral f $
