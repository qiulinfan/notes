# distribution function of mu

## Summary

给定一个 locally finite (finite on all compact sets) 的 Borel measure on $bb(R)$ (即 $\(bb(R)\,cal(B)\(b R\)\,mu\)$), 我们定义: $ F_mu\(x\):= {mu\(\(0\,x\]\)quad\,x gt.eq 0\ - mu\(\(x\,0\]\)\,x < 0 $ 这个函数被称为 $mu$ 的 distribution function.
