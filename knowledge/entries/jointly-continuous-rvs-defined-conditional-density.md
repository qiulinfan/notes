# jointly continuous RVs 之间所有 defined 处总有 conditional density

## Summary

若 (X,Y)^T 是 continuous random vector，则在 f_Y(y)>0 的每个 y 上，X given Y=y 有 conditional density f_{X|Y}(x|y)=f_{X,Y}(x,y)/f_Y(y)。
