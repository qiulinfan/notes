# Carathéodory theorem

## Summary

对于任意的 outer measure $mu^(*)$, $ cal(M) := { upright("all ") mu^(*) upright("-measurable sets") } $is a [$sigma$-algebra]. \ 并且, $mu^(*)\|_(cal(M))$ is a complete measure.
