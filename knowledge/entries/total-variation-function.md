# total variation function

## Summary

给定一个 function $F : bb(R) arrow.r bb(C)$, 我们定义它的 total variation function $T_F$ 为:$ T_F : bb(R) & arrow.r\[0\,oo\]\ x & mapsto sup { sum_(j = 1)^n\|F\(x_j\)- F\(x_(j + 1)\)\|: - oo < x_0 < dots.h.c < x_n = x } $
