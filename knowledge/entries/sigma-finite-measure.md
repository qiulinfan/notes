# σ-finite measure

## Summary

Let $\(X\,cal(M)\,mu\)$ be a measure space. \ 如果 $mu\(X\)< oo$, 则称 $mu$ 是 finite 的. \ 如果存在一个 sequence $\(E_i\)$ in $cal(M)$ 使得 $union.big_i E_i = X$ 并且每个 $mu\(E_i\)< oo$, 则称 $mu$ 是 $sigma$-finite 的.
