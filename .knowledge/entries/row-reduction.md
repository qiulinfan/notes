# row reduction

## Summary

任意 invertible linear map 可以被拆分为 finite 个 elementary linear maps. ( $T_1$: scale 一行; $T_2$: 交换两行; $T_3$: 一行加上另一行的倍数).

## Evidence

```
\begin{lemma}{\kn{row reduction}}

\textbf{任意 invertible linear map 可以被拆分为 finite 个 elementary linear maps.} ( \(T_{1}\): scale 一行; \(T_{2}\): 交换两行; \(T_{3}\): 一行加上另一行的倍数).

\end{lemma}
```
