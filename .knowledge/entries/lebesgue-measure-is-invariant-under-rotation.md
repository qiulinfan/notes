# Lebesgue measure is invariant under rotation

## Summary

对于 rotation 和 reflection (即 orthogonal transformation), 即 $T T^(*) = I_n$ 的 linear map $T$, 有 $m\(T\(E\)\)= m\(E\)$.

## Evidence

```
\begin{corollary}{\kn{Lebesgue measure is invariant under rotation}}

对于 rotation 和 reflection (即 orthogonal transformation), 即 \(TT^{\ast} = I_{n}\) 的 linear map \(T\), 有 \(m(T(E)) = m(E)\).

\end{corollary}
```
