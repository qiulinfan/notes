# real-valued integrable function

## Summary

Given measure space $\(X\,cal(M)\,mu\)$, measurable $f : X arrow.r accent(bb(R), macron)$ 被称为 integrable 的, 如果它满足 $ integral\|f\|< oo $ 并定义其 integral 为: $ integral f = integral f^(+) - integral f^(-) $

## Evidence

```
\begin{definition}{\kn{real-valued integrable function}}

Given measure space \((X,\mathcal{M},\mu)\), \textbf{measurable \(f:X\rightarrow\bar{\mathbb{R}}\) 被称为 integrable} 的, 如果它满足

\[\left. \int \middle| f \middle| < \infty \right.\]

\[\int f = \int f^{+} - \int f^{-}\]
```
