# h-intervals form an algebra and generate borel set

## Summary

$ cal(A)_0 := { upright("finite (disjoint) unions of h-intervals") } $ 是一个 algebra, 并且 $ < cal(A)_0 > = cal(B)\(bb(R)\) $

## Evidence

```
\begin{lemma}{\kn{h-intervals form an algebra and generate borel set}}

\[\mathcal{A}_{0} := \left\{ \text{finite (disjoint) unions of h-intervals} \right\}\]

是一个 algebra, 并且

\[< \mathcal{A}_{0} > = \mathcal{B}(\mathbb{R})\]

\end{lemma}
```
