# cdf 一定是 N B V 的

## Summary

CDF 是 normalized bounded-variation 函数。

## Evidence

```
\begin{lemma}{\kn{cdf 一定是 $\mathit{N}\mathit{B}\mathit{V}$ 的}}

任意的 random variable 的 cdf \(\mathit{F}_{\mathit{X}}\) 都是一个 \(\mathit{N}\mathit{B}\mathit{V}\) function.

\end{lemma}
```
