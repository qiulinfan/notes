# 每个 L^m 函数都是一个 L^n 函数和一个 L^r 函数的和 (0 < n < m < r leq infty)

## Summary

对于任意的 $0 < n < m < r lt.eq oo$, 都有 $ L^m subset\(L^n + L^r\) $

## Evidence

```
\begin{proposition}{\kn{每个 $L^m$ 函数都是一个 $L^n$ 函数和一个 $L^r$ 函数的和
($0 < n < m < r \leq \infty$)}}

对于任意的 \(0 < n < m < r \leq \infty\), 都有

\[L^{m} \subset (L^{n} + L^{r})\]

\end{proposition}
```
