# approximating a nonneg measurable function by simple function

## Summary

任意的 measurable $f : X arrow.r\[0\,oo\]$ 都是 pointwise limit of an increasing sequence of simple functions ${ phi.alt_n : X arrow.r\[0\,oo\]}_(n in bb(N))$.

## Evidence

```
\begin{theorem}{\kn{approximating a nonneg measurable function by simple function}}\label{thm-04-measurable-functions-and-integration-on-l-mu-approximating-a-nonneg-measurable-function-by-simple-function}

任意的 measurable \(f:X\rightarrow\lbrack 0,\infty\rbrack\) 都是 \textbf{pointwise limit} of an \textbf{increasing sequence of simple functions} \(\left\{ {\varphi_{n}:X\rightarrow\lbrack 0,\infty\rbrack} \right\}_{n \in \mathbb{N}}\).

\end{theorem}
```
