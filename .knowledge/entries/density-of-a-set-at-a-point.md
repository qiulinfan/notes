# density of a set at a point

## Summary

对于 $E subset bb(R)^n$ Lebesgue measurable (which implies: $chi_E in L_(l o c)^1$), 我们定义: $ D_E\(x\): = lim_(r arrow.r 0^(+)) frac(m\(E inter B\(x\,r\)\), m\(B\(x\,r\)\)) $

## Evidence
