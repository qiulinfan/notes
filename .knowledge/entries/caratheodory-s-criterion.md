# Caratheodory's criterion

## Summary

In the IBL notes, a set is measurable exactly when the stated elementary-test-set equality holds for every elementary set.

## Evidence

```
\begin{theorem}{\kn{Caratheodory's criterion} --- elementary test sets}

A set \(E \subseteq \mathbb{R}^{n}\) is measurable if and only if for every elementary set \(A\), \(m(A) = m^{\ast}\left( {A \cap E} \right) + m^{\ast}\left( {AE} \right)\).

\end{theorem}
```
