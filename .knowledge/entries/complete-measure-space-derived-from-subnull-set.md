A measure space is complete exactly when all of its subnull sets are measurable null sets.

## Evidence

> \begin{definition}{\kn{complete measure space}}
>
> 我们称 \((X,\mathcal{M},\mu)\) 是一个 complete measure space, 如果它其中的任意 subnull set 都是 null set. (即它 measurable)
>
> \end{definition}
