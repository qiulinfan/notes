# mutually singular

## Summary

我们称两个 signed measure $nu_1\,nu_2$ on $\(X\,cal(A)\)$ 是 mutually singular 的, 如果 $X = E_1 union.sq E_2$, 其中 $E_i$ 是 $nu_i$ 的 null set. \ 简单而言就是: 这两个 measure 可以把 live on disjoint sets, 在对方 live on 的部分总是 null 的.
