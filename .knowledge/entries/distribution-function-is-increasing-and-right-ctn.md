# distribution function is increasing and right ctn

## Summary

对于 $bb(R)$ 上的任意 locally finite Borel measure $mu$, 其 distribution function $F_mu$ 都是 increasing 且 right continuous 的. (right ctn:$ F_mu\(a\)= lim_(x arrow.r a^(+)) f\(x\) $

## Evidence

```
\begin{theorem}{\kn{distribution function is increasing and right ctn}}

对于 \(\mathbb{R}\) 上的任意 locally finite Borel measure \(\mu\), 其 distribution function \(F_{\mu}\) 都是 increasing 且 right continuous 的. (right ctn:

\[F_{\mu}(a) = \lim\limits_{x\rightarrow a^{+}}f(x)\]

\end{theorem}
```
