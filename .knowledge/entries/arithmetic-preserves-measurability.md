# addition and multiplication preserve measurability

## Summary

如果 $f\,g$ 是 $cal(M)$-measurable function, 那么 $f + g\,f g$ 也是.

## Evidence

```
\begin{proposition}{\kn{addition and multiplication preserve measurability}}

如果 \(f,g\) 是 \(\mathcal{M}\)-measurable function, 那么 \(f + g,fg\) 也是.

\end{proposition}
```
