给定 signed measure $nu$, 对于 $E in cal(A)$, 我们称 $E$ 是一个 postive set, 如果对于对于任意的 $F subset E$, 都有 $ nu\(F\)gt.eq 0 $ negative set 和 null set 同理. \ Note: For signed measure, 一个集合的 signed measure 为 $0$ 并不代表它的任何子集的 measure 也是 $0$, 它可以是两个正负 measure 相抵的集合的 union. 因而我们要这样额外定义 null set.
