# L^1(μ) space

## Summary

我们定义 $L^1\(X\,mu\,bb(C)\)$, 或简称为 $L^1\(mu\)$, 为:$ tilde(L)\(X\,mu\,bb(C)\)\/tilde.op $ 其中 $tilde.op$ 表示一个 equivalent class: $f tilde.op g$ if $f = g$ a.e. (等价于 $integral\|f - g\|= 0$)

## Evidence

```
\begin{definition}{\kn{$L^1(\mu)$ space}}

我们定义 \(L^{1}(X,\mu,\mathbb{C})\), 或简称为 \(L^{1}(\mu)\), 为:

\[\widetilde{L}(X,\mu,\mathbb{C})/ \sim\]

其中 \(\sim\) 表示一个 equivalent class: \(f \sim g\) if \(f = g\) a.e. (等价于 \(\left. \int \middle| f - g \middle| = 0 \right.\))

\end{definition}
```
