# (real-valued) measurable functions

## Summary

Let $\(X\,cal(A)\)$ be a measurable space, 对于 $f : X arrow.r accent(bb(R), macron)$ 如果它是 $\(cal(A)\,cal(B)\(accent(bb(R), macron)\)\)$-measurable 的, 我们直接简称它是 $cal(A)$-measurable 的, 或者简称为 measurable 的.
