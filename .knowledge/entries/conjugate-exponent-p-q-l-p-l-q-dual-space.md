# 对于互为 conjugate exponent 的 p,q, L^p 是 L^q 的 dual space

## Summary

For $1 < p\,q < oo$ with $1 / p + 1 / q = 1$, we have: $ \(L^p\)^(*)= L^q $ In particular the Hilbert space: $ \(L^2\)^(*)= L^2 $

## Evidence

```
\begin{theorem}{\kn{对于互为 conjugate exponent 的 $p,q$, $L^p$ 是 $L^q$ 的 dual
space}}

\knref{l-p-spaces} 给出这里的 \(L^{p}\) 与 \(L^{q}\) 空间。\\
For \(1 < p,q < \infty\) with \(\frac{1}{p} + \frac{1}{q} = 1\), we have:

\[(L^{p})^{\ast} = L^{q}\]

In particular the Hilbert space:

\[(L^{2})^{\ast} = L^{2}\]

\end{theorem}
```
