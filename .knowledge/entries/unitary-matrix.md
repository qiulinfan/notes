# Unitary matrix

## Summary

A square complex matrix Q satisfying Q* = Q^(-1), equivalently having orthonormal rows and columns.

## Evidence

```
\begin{definition}{\kn{Unitary matrix}}

一个 square matrix \(Q \in \mathbb{C}^{m \times m}\) 被称为 unitrary 的，if \(Q^{\ast} = Q^{- 1}\)。

\end{definition}
```
