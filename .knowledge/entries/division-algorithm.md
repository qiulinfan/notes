# Division algorithm

## Summary

For integers n and positive d, there are unique integers q and r such that n = qd + r with 0 <= r < d.

## Evidence

```
\begin{theorem}{\kn{Division algorithm}}

For \(n,d \in \mathbb{Z}\) with \(d > 0\), there are unique \(q,r \in \mathbb{Z}\) such that

\[n = qd + r\quad \land \quad 0 \leq r < d.\]

\end{theorem}
```
