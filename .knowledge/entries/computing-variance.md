# computing variance

## Summary

Var(X)=E[X²]−E[X]²，并给出平移和缩放规则。

## Evidence

```
\begin{proposition}{\kn{computing variance}}

对于 random variable \(\mathit{X}\) with finite expectation,

\[\text{Var}(\mathit{X}) = \mathbb{E}\lbrack\mathit{X}^{2}\rbrack - (\mathbb{E}\lbrack\mathit{X}\rbrack)^{2}\]

\end{proposition}
```
