# First isomorphism theorem

## Summary

A surjective group homomorphism f:G→H induces an isomorphism G/ker f ≅ H.

## Evidence

```
\begin{theorem}{\kn{First isomorphism theorem}}

If \(f:G\rightarrow H\) is a surjective group homomorphism, then

\[\frac{G}{\ker}f \sim = H.\]

\end{theorem}
```
