# Hardy-Littlewood maximal function

## Summary

对于 $f in L_(l o c)^1$, 我们定义它的 HL maximal function 为: $ H f\(x\): = sup_(r > 0) A_r\|f\|\(x\) $

## Evidence

```
\begin{definition}{\kn{Hardy-Littlewood maximal function}}

对于 \(f \in L_{loc}^{1}\), 我们定义它的 HL maximal function 为:

\[\left. Hf(x): = \sup\limits_{r > 0}A_{r} \middle| f \middle| (x) \right.\]
```
