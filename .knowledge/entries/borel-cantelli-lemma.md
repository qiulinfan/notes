# Borel--Cantelli Lemma

## Summary

一个 measure 和有限的 set seq, 其 $lim sup$ (出现 infinitely many times 的元素) 是零测的.

## Evidence

```
\begin{theorem}{\kn{Borel--Cantelli Lemma}}

一个 measure 和有限的 set seq, 其 \(\lim\sup\) (出现 infinitely many times 的元素) 是零测的.

\end{theorem}
```
