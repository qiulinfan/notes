# (complex-valued) measurable functions

## Summary

如果 $f : X arrow.r bb(C)$ 满足: $"Re" f\,"Im" f$ 都是 (real-valued) $X$-measurable 的, 那么也称 $f$ 是 $X$-measurable 的, 或者直接说是 measurable 的.
