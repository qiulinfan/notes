# Young's inequality for products

## Summary

Whenever $p\,q in\(1\,oo\)$ with $1 / p + 1 / q = 1$, 都有 $ a b lt.eq a^p / p + b^q / q\,quad forall a\,b gt.eq 0 $ where equality is achieved if and only if $a^p = b^q$. \ 另一个等价形式是: $ a^lambda b^(1 - lambda) lt.eq lambda a +\(1 - lambda\)b\,quad forall a\,b gt.eq 0 $

## Evidence

```
\begin{lemma}{\kn{Young's inequality for products}}

Whenever \(p,q \in (1,\infty)\) with \(\frac{1}{p} + \frac{1}{q} = 1\), 都有

\[ab \leq \frac{a^{p}}{p} + \frac{b^{q}}{q},\quad\forall a,b \geq 0\]

where equality is achieved if and only if \(a^{p} = b^{q}\).\\
另一个等价形式是:

\[a^{\lambda}b^{1 - \lambda} \leq \lambda a + (1 - \lambda)b,\quad\forall a,b \geq 0\]

\end{lemma}
```
