# integral restricted to a measurable set

## Summary

if $f in tilde(L)\(X\,mu\,bb(C)\)$, $E in cal(A)$ ($mu$ 的 $sigma$-algebra), 我们 define: $ integral_E f thin d mu := integral f chi_E thin d mu $

## Evidence

```
\begin{definition}{\kn{integral restricted to a measurable set}}

if \(f \in \widetilde{L}(X,\mu,\mathbb{C})\), \(E \in \mathcal{A}\) (\(\mu\) 的 \(\sigma\)-algebra), 我们 define:

\[\int_{E}f\, d\mu := \int f\chi_{E}\, d\mu\]

\end{definition}
```
